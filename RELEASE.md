## 2. Установщик сервера (Windows)

В папке сервера BookReader:
- `install.bat` — установщик: соглашение → проверка ПК → свой Python 3.12 (в папку `python`,
  системный не трогается) → Visual C++ и правило брандмауэра (один запрос прав администратора) →
  PyTorch (для видеокарты NVIDIA или процессора — выбирается сам) → библиотеки → модель Silero →
  `BookReader.exe` и ярлыки на рабочем столе и в «Пуске» → самопроверка. Прогресс — полосой и по шагам,
  журнал — `%TEMP%\BookReader_install.log` (копия — `%LOCALAPPDATA%\BookReader\logs\install.log`). Повторный запуск доустанавливает недостающее.
- `uninstall.bat` — удаление того, что поставил установщик.
- На шаге 2 установщик показывает найденные видеокарты и предлагает выбор:
  - **Видеокарта NVIDIA (CUDA)** — рекомендуется, если у NVIDIA **4 ГБ видеопамяти и больше** и драйвер поддерживает
    CUDA 11.8+. Озвучка в десятки раз быстрее; загрузка ~3 ГБ.
  - **Процессор (CPU)** — рекомендуется во всех остальных случаях. **Видеокарты AMD и Intel — только этот вариант**
    (PyTorch для Windows работает с видеокартами только через CUDA). Загрузка ~250 МБ.
  Голоса и качество одинаковые, разница только в скорости. Сменить выбор: `install.bat -Gpu` или `install.bat -Cpu`
  (сборка torch заменится). `-Yes` — без вопросов, по рекомендации.

Как раздать: `build-server.bat` соберёт архив `dist\BookReader_Server_vX.Y.Z.zip` (см. п. 4) → на новом ПК распаковать
в папку с правом записи (например, «Документы»; не в Program Files) и запустить `install.bat`.

Проверка перед релизом: `python tests/test_server.py` (сервер в тестовом режиме, модель не нужна).

## 3. APK (Android)

«Лицензионный ключ» для APK — это **ключ подписи**: Android ставит только подписанные приложения,
а обновление встаёт поверх старой версии, только если подписано тем же ключом.

1. Запустите `build-apk.bat` в корне `BookReaderClient`. Скрипт по шагам:
   - показывает, какие APK уже собраны в `dist` (версии, размер, дата);
   - спрашивает, какое это обновление: **1 — минорное** (исправления, 1.0.0 → 1.0.1), **2 — среднее**
     (новые возможности, → 1.1.0), **3 — большое** (→ 2.0.0) или **4 — пересобрать** ту же версию;
   - проверяет папку ключа `%USERPROFILE%\BookReader-keys`: ключ есть — спрашивает пароль и сразу его проверяет;
     ключа нет — предлагает создать новый или указать файл из резервной копии;
   - записывает версию в `BookReaderClient.csproj` (код версии для Android считается сам: X·10000 + Y·100 + Z — всегда растёт)
     и собирает подписанный APK.
2. При создании ключа **сохраните копию папки ключа и пароль** — без них обновить приложение у пользователей не получится.
3. Готовый файл: `dist\BookReader-X.Y.Z.apk` (+ `.sha256`), что нового — в `dist\CHANGELOG.txt`.
   Без вопросов: `build-apk.bat -Bump patch -Notes "что нового"`.
4. Установка на телефон: скопировать APK → открыть → разрешить «Установку из неизвестных источников» для
   файлового менеджера/браузера.

## 4. Архив сервера

`build-server.bat` в папке сервера → `dist\BookReader_Server_vX.Y.Z.zip`: тот же выбор обновления, версия — в `server.py`,
перед сборкой — самопроверка сервера. В архив попадает только нужное для установки (белый список).

То же можно сделать в Visual Studio: конфигурация Release → ПКМ по проекту → «Опубликовать…» →
«Ad Hoc» → создать/выбрать ключ.

Смарт-часы: интерфейс адаптирован под экраны от 200 px, но на Wear OS нет системного WebView,
поэтому это приложение там не запустится — для часов нужен отдельный нативный клиент.

## 5. Открытый исходный код: что не публиковать

В оба проекта добавлен `.gitignore` — перечисленное ниже в репозиторий не попадёт, но проверьте перед первой публикацией
(`git status`):

- **Книги из `catalog`** — чужие произведения под авторским правом. В репозитории остаётся только `catalog/ПРОЧТИ.txt`.
- **Ключ подписи APK** (`%USERPROFILE%\BookReader-keys\*.keystore`) — лежит вне проектов; никогда не кладите его в репозиторий.
- `python/`, `BookReader.exe`, `__pycache__/`, `data/cmudict.dict` (скачивается сам), `bin/`, `obj/`, `dist/`, `.vs/`.
- `BookReaderClient/local.props` и `*.csproj.user` — ваши локальные пути и настройки Visual Studio.

Настройки сервера, журналы и библиотека пользователя хранятся вне папок проектов (в `%LOCALAPPDATA%\BookReader`,
в браузере и в памяти телефона), поэтому в репозиторий не попадают.

Идентификатор Android-приложения по умолчанию — `io.github.bookreader.client`. Если у вас уже установлена сборка
со старым идентификатором и вы хотите, чтобы новая встала поверх неё (с сохранением библиотеки), укажите его
в `local.props` (см. README клиента).

# BookReaderClient — приложение BookReader для Android и Windows

.NET 10 MAUI. Внутри — тот же интерфейс читалки, что на ПК (HybridWebView), снаружи — нативные части:

| Что | Где |
|---|---|
| Книги | на устройстве: файлы `AppData/books/*.bin` + карточки в SQLite `library.db3`. Без синхронизации |
| Озвучка | сервер BookReader на ПК — приложение находит его в сети само или по адресу из настроек |
| Проигрывание | нативный плеер. На Android — фоновый сервис с уведомлением ⏮ ⏯ ⏭ ✕, кнопки гарнитуры и экрана блокировки, читает при погашенном экране |
| Настройки | «Подключение к серверу»: статус сервера (онлайн / не отвечает, адрес, версия), «Проверить соединение», «Найти сервер в сети», адрес вручную |

Веб-интерфейс **не копируется** в проект: при сборке берётся из папки `web` сервера BookReader (свойство `WebUiDir`).
По умолчанию — соседняя папка: `../BookReader/web` (или `../FB2Reader/web`) рядом с папкой `BookReaderClient`.
Поменяли что-то в читалке на ПК — пересоберите приложение, и оно получит те же изменения.

## Сборка

Нужно: Visual Studio 2026 с нагрузкой «Разработка .NET MAUI» (или `dotnet workload install maui-android maui-windows`).

1. Удалите папки `BookReaderClient\bin` и `BookReaderClient\obj` (остались от консольного шаблона).
2. Откройте `BookReaderClient.slnx`.
3. **Windows**: цель «Windows Machine» → F5.
4. **Android**: телефон с включённой отладкой по USB (или эмулятор) → выбрать его → F5.

APK для установки без кабеля — **`build-apk.bat`**: показывает уже собранные версии в `dist`, спрашивает, какое это
обновление (минорное / среднее / большое / пересобрать), проверяет ключ подписи в `%USERPROFILE%\BookReader-keys`
(создаст новый или возьмёт из резервной копии), записывает версию в проект и собирает `dist\BookReader-X.Y.Z.apk`.
Подробно — в `RELEASE.md`. Быстрая отладочная сборка без своего ключа: `dotnet publish BookReaderClient -f net10.0-android -c Release`.

Выкладывать APK — в выпуск **публичного репозитория сервера** (`BookReader`), рядом с архивом сервера: по файлу
`BookReader-X.Y.Z.apk` в последнем стабильном выпуске приложение узнаёт о новой версии (Настройки → «Проверить
обновления»). «Что нового» в окне обновления — только блок `<!-- bookreader:whatsnew -->…<!-- /bookreader:whatsnew -->`
из описания выпуска (подробно — `RELEASE.md` сервера, раздел 6).

Если сервер лежит в другом месте — скопируйте `BookReaderClient/local.props.example` в `local.props` и укажите
`WebUiDir`, либо `dotnet build -p:WebUiDir=путь/к/web`. Там же задаётся свой `ApplicationId` (по умолчанию
`io.github.bookreader.client`): нужен, если у вас уже стоит сборка с другим идентификатором и новая должна встать поверх.
`local.props` не публикуется (`.gitignore`).

## Подключение

1. На ПК запустите BookReader (ярлык на рабочем столе или `BookReader.bat`). В окне сервера будет строка «Адрес для телефона».
2. При первом запуске Windows спросит про брандмауэр — разрешите Python для **частных** сетей.
   Если вопроса не было, а телефон не подключается: «Брандмауэр Защитника Windows» → «Разрешить взаимодействие с приложением» → python.exe → «Частная».
3. В приложении: «Подключение к серверу» → «Найти сервер в сети» (или адрес вручную → «Проверить и сохранить»).
4. Вне дома — адрес ПК в вашей VPN; телефон тоже должен быть в этой сети.

### Инструменты разработчика (скрытый экран)
На экране «Подключение к серверу» — **долгое нажатие** на строку версии внизу (или 5 нажатий подряд).
Технический журнал там же: поиск сервера и проверки пишутся в него всегда; «Копировать журнал» — в буфер обмена.
- **Ping ×4** — ICMP. На части Android-телефонов без root ICMP запрещён — это нормально, смотрите TCP/HTTP.
- **TCP-порт** — открыт ли порт 8765: «отказ» = ПК доступен, но сервер не запущен; «нет ответа» = другая сеть/брандмауэр/ПК выключен.
- **HTTP /api/ping** — сервер BookReader отвечает и сколько это занимает.
- **Голоса /api/info**, **Тест синтеза** — сервер реально синтезирует и звук доходит (фраза проигрывается).
- **IP этого устройства** — сравнить подсеть с адресом ПК.
- **Версии** — версия приложения, Android/Windows и встроенного SQLite (должна быть 3.50.2+, см. CVE-2025-6965).

## Отладка веб-части внутри приложения
Debug-сборка включает инструменты разработчика WebView:
- Windows — F12 в окне приложения;
- Android — `chrome://inspect` в Chrome на ПК (телефон по USB).

## Озвучка без интернета

Оглавление → «Озвучка без интернета…» (или «⋯» у книги в библиотеке): выбрать голос и всю книгу либо главы «с — по».
Сервер (версия 1.2+) озвучивает фразы пакетами — на видеокарте, если она доступна, — и отдаёт их в Ogg Opus 32 кбит/с
(~14 МБ на час звука). Файлы лежат в памяти приложения: `audio/{книга}/{голос}/*.oga`, декодируются в C# (пакет Concentus).
Загрузка идёт в фоне (служба Android с уведомлением). В списке книг видно: «✓ офлайн», «◐ скачано N%», «☁ озвучка с сервера».
Без сервера приложение берёт голоса из последнего ответа сервера и читает скачанные книги.
